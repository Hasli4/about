# Система страниц программ

Теперь все страницы направлений работают через:

- одну универсальную страницу: `program.html`
- один файл данных: `assets/data/programs.json`

Открытие конкретной программы выглядит так:

```text
program.html?slug=web-development
```

## Что редактировать

Все тексты и картинки меняются только в файле:

```text
assets/data/programs.json
```

У каждой программы есть свой объект со структурой:

```json
{
  "slug": "web-development",
  "title": "Веб-разработка",
  "lead": "Короткое описание",
  "chips": ["10+ лет", "С нуля", "Онлайн и офлайн"],
  "summary": [
    { "label": "Формат", "value": "..." }
  ],
  "image": {
    "src": "assets/images/courses/web_development_quad.webp",
    "alt": "..."
  },
  "description": ["Абзац 1", "Абзац 2"],
  "facts": [
    { "label": "Возраст", "value": "..." }
  ],
  "benefits": [
    { "title": "Преимущество", "text": "..." }
  ],
  "skills": ["Навык 1", "Навык 2"],
  "works": [
    { "image": "...", "alt": "...", "title": "...", "text": "..." }
  ],
  "faq": [
    { "question": "...", "answer": "..." }
  ]
}
```

## Как изменить существующую программу

1. Откройте `assets/data/programs.json`.
2. Найдите нужный объект по полю `"slug"`.
3. Измените тексты, подписи и пути к изображениям.
4. Сохраните файл.

## Как добавить новую программу

1. Скопируйте любой готовый объект в `assets/data/programs.json`.
2. Поменяйте у копии `"slug"` на новый уникальный.
3. Измените заголовок, тексты и картинки.
4. Если новая программа должна открываться с главной страницы, добавьте или измените ссылку карточки в `index.html`:

```text
program.html?slug=your-new-slug
```

## Где менять картинки

Лучше складывать новые изображения сюда:

```text
assets/images/courses/
```

или использовать уже существующие картинки из:

```text
assets/images/portfolio/
```

После этого просто укажите путь в `programs.json`.

## Важно про локальный просмотр

Если открыть `program.html` двойным кликом как обычный файл, браузер может заблокировать чтение `programs.json`.

В этом случае используйте локальный сервер, например:

```bash
python -m http.server 8000
```

Потом откройте:

```text
http://localhost:8000/program.html?slug=web-development
```

## Что уже подключено
